--> 013 - Efeito de perder

Variáveis globais são sempre bons no script porque eles rodam antes de qualquer coisa

O comando "with" roda o código dentro da outra pessoa Exemplo: with(obj_arvore)
{ hspeed = 0; }

O problema disso é que se a árvore não existe o código dá erro

Mas eu quero fazer com que tudo pare, e para isso posso usar a palavra "all",
ele vai rodar em todo mundo que existe no jogo
with(all) { hspeed = 0; }

ISSO TAMBÉM INCLUI O PLAYER
por isso para evitar problemas, mude o "hspeed" do player logo em seguida

--> 016 - Resolução da atividade

Uma função é um agregado de códigos rodando,
basicamente você pode criar uma função que é a conjunção de vários códigos em um só

Funções são laranjas

O ideal é criar funções em scripts porque funções são globais,
logo sendo um dos principais propósitos de um script

Caso o jogo seja grande é recomendado criar scripts para diferentes propósitos

Por exemplo um script para variáveis globais, um para funções de recursos, 
ou funções de jogo, funções de inventário, funções de menu, etc...

Scripts após criados já iniciam o código com uma estrutura de função justamente para isso

A próxima aula será puramente focada em funções, servindo como uma introdução

//////////////////////////////////////////////////////////////////////////////////////////

--> 017 - Introdução a funções

Para criar função você primeiro escreve "function",
depois você coloca o nome da função, quando terminar de colocar nome
você abre e fecha parênteses

Exemplo: function perde_jogo()

Depois você vai abrir e fechar chaves, para poder escrever o código dentro

Exemplo: function perde_jogo() 
		 { 
			//código da função 
		 }

Tudo escrito dentro das chaves será rodado sempre que a função for mencionada

Também é possível fazer condições "exit" nas funções
