--> 023 - Iniciando o sistema de pontos

A posição que o "Draw GUI" utiliza não é a posição da câmera, nem da room, 
é a posição do VIEWPORT, a posição do VIEWPORT pode ser diferente da câmera

Logo o GUI é desenhado na TELA do jogo, não é desenhado dentro do jogo

A atividade é fazer o player não ganhar ponto após perder

--> 025 - Criando a fonte e arredondando os pontos

Enable SDF ajuda a renderizar as fontes de jeito que fica um pouquinho melhor.
Essa configuração pode ser ativada dentro da fonte

Fontes podem não ter "ç" ou acentos,
para resolver isso basta clicar em "Add" (Add new range)

Nele você poderá ver tudo o que a fonte tem, 
separando em filtros tipo só digitos, só letras,
e até mostrar tudo através do ASCII, incluindo símbolos

Para incluir caracteres não presentes na fonte você clica em "Add Range"

Qualquer função que seja "draw_set" é global,
logo para resetar o "draw_set_font" você faz "draw_set_font(-1)"
já que "-1" reseta essa função

--> 029 - Introdução a arrays

Array é uma variável que pode ter vários valores

Array é basicamente uma lista, é tipo uma tabela.

Para criar uma array você abre e fecha colchetes "[ ]" 
Exemplo: global.lista_pontos = [ ]

Tudo que está dentro dos colchetes são itens dele

A gente vai colocando vírgula para criar cada um dos itens.
Exemplo: global.lista_pontos = [100, 250, 500, ...]

Para ver um item em específico da lista você abre colchetes 
após referenciar a variável e coloca o número dela

(IMPORTANTE: ARRAYS NÃO COMEÇAM DO 1, 2, 3... ELAS COMEÇAM DO 0, 1, 2, 3...)

Logo, para ver o primeiro índice você coloca 0

Garanta que você está ficando dentro do limite dela,
pedir por um número maior do que a quantidade de números
disponíveis na array causa um crash

Logo se uma array só tem 6 itens, pedir pelo "item 7" causa problemas
